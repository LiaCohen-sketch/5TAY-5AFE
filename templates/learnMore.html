About Phishing URLs:

How To Recognize Phising URL With Common Signs:

1. "Typosquatting" - the URL will have letters or numbers that are similiar to the original domain but will be different letters then what in the original URL. Example: capital 'I' instead of small 'l', switching 'o' in '0', and more.

2. Make sure the URL has the right end. Example - Real = 'www.google.com' Fake = 'www.google.co'

3. Do not go into links that start with 'HTTP' and not 'HTTPS' - Even though today phishing URls has the 'S' if it doesn't then it's phishing. Example: Real = 'https://www.google.com' Fake = 'http://www.google.com'

4. If the URL has @ in the middle, the URL its phishing because the website ignores the text that comes before it. Example: 'facebook.com@blank.top' if you'll press the link, it will only read the '@blank.top' part.

5. If the URL ends with suspicios ending like, '.exe', '.zip', '.src' and more it's likely to be phising. Example: 'facebook.exe'
